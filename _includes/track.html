{% if site.gtag %} {%- comment -%} VoteGA event tracking — a thin, privacy-respecting wrapper over GA4 (gtag.js). Principles: - No personal data is ever sent. Callers pass only coarse, non-identifying values (outcomes, counts, tab names, category labels). The address tools (Find My Reps, Sample Ballot) report only success/failure — never the address, coordinates, or resolved districts tied to a person. - Declarative use: add data-vg-track="event_name" to any clickable element. Optional data-vg-="value" attributes become event parameters. Because this path reads only author-set attributes (never user input), no personal data can leak through it by construction. - Programmatic use: window.vgTrack('event_name', { key: 'value' }). Use this from page JS for outcome events, passing only enums/counts you control. Loaded site-wide from head.html, right after gtag.html, and guarded by the same site.gtag check so it is inert when analytics is disabled. {%- endcomment -%} {% endif %}
