{%- comment %} Tabbed layout for a /local// place page. place.html captures each domain into a variable (tab_meetings, tab_topics, tab_officials, tab_schools, tab_taxes, plus tab_notice for a bot-protected place) and includes this file to lay them out. A tab exists only when its capture rendered something, so a city with no school board roster or millage view simply has fewer tabs. With fewer than two server-rendered domains there is nothing to switch between and the sections are printed one after another, as before. Every panel is in the HTML; the script below only hides the inactive ones. A crawler, or a visitor without JavaScript, still gets the whole page. Topics ("On recent agendas") is filled client-side by local-subjects.js from the enrichment sidecar, so its button starts hidden and appears only once that section is revealed. URL hash: a tab key (#meetings, #topics, #officials, #schools, #taxes) opens that tab, and so does the id of anything inside a panel, which keeps the old section anchors working (#officials, #constitutional-officers, #school-boards, #millage, #cmMeetings, #subjects).
