--- layout: default --- {%- comment -%} Shared layout for every Georgia election-results page (primary, runoff, special, general). A results page is a thin stub: front matter points at a data file and declares how to present it. Data is built by scripts/build_results_json.py into _data/election_results/.json. Front-matter contract --------------------- results_data (required) key into _data/election_results/ (e.g. ga-special-2026-results) heading (required) the

(falls back to page.title) election_date (required) ISO date, e.g. 2026-07-28 subtitle optional shown before the date in the meta line (e.g. "U.S. House District 13") updated optional ISO date for a "Last updated" stamp status optional unofficial (default) | certified — drives labels + notice styling The status actually shown is resolved by _includes/result-status.html: until the data file holds a single vote the page reads `upcoming` whatever the front matter says, so a page can be staged with the status it will have on election night. Staged pages should also carry `noindex: true`, `sitemap: false` and `search: false` so they are not discoverable until they mean something; dropping those three flags is the whole of going live. (`preview` is still accepted and folded into `upcoming`.) results_mode optional round (default) | final round = leader wins if >50%, else top-N go to a runoff (primary/jungle) final = leader wins outright (runoff/general) runoff_advances optional how many finishers advance when a round goes to runoff (default 2) label_winner / label_runoff / label_uncontested / label_noresults optional override the auto status-badge text notice optional raw-HTML notice override; otherwise a default is shown per status notice_upcoming optional raw-HTML notice used ONLY while the page reads `upcoming` (no votes counted yet). It lets an indexable page say what to expect before election night and then fall back to the normal per-status notice on its own the moment the first vote lands — no front-matter edit. Beaten by `notice` if both are set. empty_section_text optional message for a section tab with no races {%- endcomment -%} {%- include result-status.html stub=page -%}
