How a review session works (click to hide)
  1. Start on a fresh branch. In the repo root (C:\Users\justi\Documents\GitHub\votega.org), update main and branch from it: git switch main; git pull; git switch -c ai-review-$(Get-Date -Format yyyy-MM-dd) (PowerShell; names the branch with today's date)
    Then click Open repo folder above and choose votega.org.
  2. Review. For each bill, read the caption and summary (open the bill text when a warning asks you to). Approve (A), editing the text or tags first if needed. Or write a note and Send back for redo (R). Skip (S) moves on.
    Every click is saved to _data/ga_bill_ai_decisions.json right away. Nothing reaches the site yet.
  3. Apply your decisions: python scripts/ai_enrich_ga_bills.py apply-reviews
    It lists what changed. Lines marked STALE are decisions on text that has since been refined; they are skipped, which is expected.
  4. Sent any back? Refine them (uses your Claude plan, one call per bill; add --limit 10 for a batch): python scripts/ai_enrich_ga_bills.py refine --redo-only
    Then click Reload data. They come back under "To review" with new full-text summaries. Repeat steps 2 and 3 for them.
  5. Check and commit. Run git diff --stat. All three files should change. Commit them together, push, and open a PR to main: git add _data/ga_bill_ai_decisions.json assets/data/ga-bill-ai.json assets/data/ga-bill-summaries.json
    Never edit ga-bill-ai.json by hand. apply-reviews is the only thing that should change it.
  6. After merging, it shows up: summaries on /ga-bills at the next site deploy; approved tags for untagged bills at the next Sunday update-ga-bills run (or start it by hand); Key Votes at its Tue/Thu run, only for curated bills with no summary of your own.
Follow the steps above. Start by clicking Open repo folder and choosing votega.org (the repo root).
