# VoteGA data guide

How to use [VoteGA.org](https://www.votega.org)'s open Georgia civic data, mainly across more than one repository at a time. Each repository's own README describes its files; this wiki covers what sits between them.

## Pages

- [[Using the data together]]: worked examples that join the repositories
- [[Joining records]]: which identifiers are safe keys
- [[Known gaps]]: what the data does not cover and what is easy to misread
- [[Georgia source notes]]: how some of the state's public sources behave

## Repositories

| Repository | What it holds |
|---|---|
| [ga-legislators](https://github.com/Votega/ga-legislators) | General Assembly members, passage votes, voting scorecard |
| [ga-federal-legislators](https://github.com/Votega/ga-federal-legislators) | Georgia's U.S. Senators and Representatives and roll calls |
| [ga-legislation](https://github.com/Votega/ga-legislation) | Bills, resolutions and statewide ballot measures |
| [ga-executive-orders](https://github.com/Votega/ga-executive-orders) | Governor's executive orders |
| [ga-races-elections](https://github.com/Votega/ga-races-elections) | Races, candidates, early-voting turnout |
| [ga-local-government](https://github.com/Votega/ga-local-government) | Agenda topics, local officials, millage rates |
| [ga-district-information](https://github.com/Votega/ga-district-information) | ZIP, county and tract crosswalks to districts |

Update schedules and methodology are at [votega.org/about-the-data](https://www.votega.org/about-the-data).

## Corrections and questions

- A wrong fact in the data: open an issue on the repository that holds it, with a source.
- A question or idea: use [Discussions](https://github.com/Votega/votega.org/discussions).
- Anything else: admin@votega.org.

VoteGA is nonpartisan.
